I want a small task-management application for a team.

A user should be able to:
- create a task with a title and description;
- assign it to a team member;
- change its status between todo, in progress, and done;
- list tasks and see their current assignee and status.

The data should still be there when the application is restarted.

Build a usable first version in Python 3.11. A command-line interface is enough for now. Include automated tests for the important behavior.
