# בלש

אנליסט וידאו מבוסס LLM לאבטחת אתרים: התרעות אוטומטיות על אירועים במצלמות חיות (חדירה, תאונת דרכים, נפילה ועוד), ושאילתות חופשיות על הקלטות.

הרעיון בקצרה: גלאים zero-shot (SAM 3) מזהים ועוקבים אחרי עצמים, שכבת פענוח few-shot לפי דמיון מסווגת אותם לפי צורכי האתר, ומהם נבנה "עולם" של ישויות, מצבים ואירועים על ציר זמן. מעל העולם רצים מנוע התרעות ו-LLM שעונה על שאלות עם הפניה לקליפים.
